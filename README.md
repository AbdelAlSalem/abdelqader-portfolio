## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/AbdelAlSalem/abdelqader-portfolio.git
cd abdelqader-portfolio
```

Open `index.html` in your browser, or start a local development server:

```bash
python -m http.server 8000
```

Then visit:

`http://localhost:8000`

No npm installation or build process is required.

## 🌍 Deployment

The website is hosted on **Netlify** and connected to this GitHub repository for continuous deployment.

The deployment workflow is:

1. Update the source code locally.
2. Commit and push changes to the `main` branch.
3. Netlify automatically builds and deploys the latest version.
4. The updated website becomes available at [abdelqader.dev](https://abdelqader.dev).

The production website uses a custom domain with HTTPS.
